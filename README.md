# Last Text at One Percent

An entry for the [Last Text at One Percent](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876)
bounty on [make.fun](https://make.fun): the funniest final text message a dying
phone sends at one percent battery, under 200 characters, in the phone's own voice.

## The message

> i forgive you for the toilet incident. i do NOT forgive the 47 open tabs. delete my history. 1% and out.

(104 characters — picked after a 10-candidate internal pairwise tournament; see `candidates.md`.)

## Run

```sh
python3 main.py
```

Writes the message to `/output/entry.txt` (`OUTPUT_PATH` overrides the path for local testing).
